보관함 구성
스마트 소총 보관함은 지문을 사용하여 1차 관리자가 승인 후 2차 사용자 조회를 통과한 사용자만이 소총을 보관 및 불출 할 수 있는 이중 보안 시스템을 구축한         소총 보관함 입니다.
본 시스템은 소총을 보관하는 보관함과 운영 관리를 하는 OMS PC, 실시간 소총 현황을 확인할 수 있는 총기 불출 현황으로 구성 되었습니다.
* 성능 향상을 위해 제품의 외형 및 구조물 형태가 변경될 수 있습니다.

마스터 관리자
로그인 방법은 “ 2.로그인 ” 절차에 따라 실시하며 타인에게 정보를 누설해서는 안된다.
메뉴 [관리자정보], [사용자정보], [총기현황], [총기목록], [불출내용], [이력관리] 아이콘이 활성화 된다.
보관함 설정
기본화면 좌측 상단 Network 망 구성 창에서 [보관함] 아이콘을 선택하면 다음과 같은 화면이 표시된다.
(그림3-1) Network 망
보관함 수정
기본화면 좌측 상단 Network 망 구성 창에서 보관함명을 더블 클릭하면 다음과 같은 화면이 표시된다.
(그림3-2) 보관함 구성
보관함 정보는 비활성화되어 수정할 수 없으며 보관함 Name 과 IP 정보만 수정 후 저장된다.
보관함 Network 연결
등록된 보관함과 OMS PC 사이의 Network 상태를 “ (그림3-1) Network 망 “ 구성 창에서 확인할 수 있다.
Network가 정상이면 보관함명 또는 IP가 적색(끊어진 상태)에서 녹색으로 변한다.
보관함과 Network 연결은 최대 10개까지 연결할 수 있다.
자동 연결
OMS PC가 설정한 IP의 보관함과 자동으로 연결된다.
(그림3-3) Network 정상                (그림3-4) Network 비정상
보관함 IP 확인
Network 망 구성 창 해당 보관함에 마우스를 올려놓으면 IP가 표시된다.
IP 설정 및 수정은 “ 3.2 설정 “을 참조한다.
(그림3-7) 보관함 IP 확인
소총 사용 용도별 세부내용 변경

메뉴에서 [불출내용] 아이콘을 선택하면 다음과 같은 화면이 표시된다.
(그림3-8) 불출현황
각 항목별 변경할 내용을 등록 후 저장하면 수정 내용이 변경되어 다시 표시된다.
수정을 원하지 않을 경우 빈 공간으로 하고 항목을 빈 공간으로 표시할 경우 작성란에 “ @@ ”로 작성하여 저장하면 항목이 표시되지 않는다.
불출현황 등록 및 수정은 총기를 불출한 이후에는 할 수 없으며 반드시 불출 전에만 기록할 수 있다.
변경된 사항은 기본 화면에 자동으로 수정되어 표시된다.
(그림3-9) 불출현황
소총 보관 현황의 내용은 수정할 수 없다.
관리자 정보등록
마스터 관리자, 서브 관리자, 운영자 정보를 등록한다.
마스터 관리자
마스터 관리자는 4명까지 등록할 수 있으며 최초 관리자 와 확장 관리자 등록 절차는 다르지만 권한은 동일하다.
이미 등록된 마스터 관리자는 확장 마스터 관리자 등록을 승인한다.
마스터 관리자 지문등록 전에만 OMS에서 정보를 삭제 할 수 있다. 지문 등록 후에는 권총 보관함에서 삭제 후 OMS에서 삭제가 가능하다.
로그인 ID, Password는 영문 소문자, 숫자, 기호를 포함하여 10자리까지 사용 할 수 있다.
최초 마스터 관리자
마스터 관리자로 등록된 정보가 없는 상태에서 최초 관리자 정보를 등록한다.
최초 관리자 등록
마스터 관리자 삭제는 마스터 관리자만 삭제할 수 있어 신중히 등록하여야 한다.
메뉴 [관리자정보], [사용자정보], [총기현황], [총기목록], [불출내용], [이력관리] 아이콘이 비활성화로 등록 전까지는 선택할 수 없다.
[로그인] 아이콘을 선택한다.
(그림4-1) 로그인
등록을 위한 ID 와 Password 을 입력한다. 이 때 임의 정보를 입력하여도 상관없다.
(그림4-2) 로그인 정보 없음
[YES]을 선택한다.
정보 등록창이 다음과 같이 표시된다.
(그림4-3) 마스터 관리자 정보 등록
계급 4 자리, 성명 5 자리, 군번 10 자리, ID 10 자리, Password 10 자리까지 등록할 수 있다.
계급, 성명은 한글로 군번은 숫자로 ID, Password는 영문 소문자, 숫자, 기호를 모두 포함하여 입력 할 수 있다.
Password를 2번 입력 하고 [확인]을 누르고 일치할 경우 저장을 할 수 있다.
Password를 2번 입력 하고 [확인]을 눌렀을 때, 일치 하지 않을 경우 다음과 같은 메시지가 표시 된다.
(그림4-4) Password 불일치
개인정보가 입력 되지 않았을 때 해당되는 미 입력된 정보에 대해 다음과 같은 메시지가 표시 된다.
(그림4-5) 정보 미 입력
위 등록 절차는 마스터 관리자 4명이 모두 등록 안 된 상태에서 최초 마스터 관리자 등록이다.
확장 마스터 관리자
최초 마스터 관리자 등록 또는 1인 이상 마스터 관리자가 있다면 로그인 후 확장 마스터 관리자를 등록할 수 있다.
확장 관리자 등록
등록된 마스터 관리자가 로그인 한다.
메뉴에서 [관리자정보] 아이콘을 선택하면 다음과 같은 화면이 표시된다.
(그림4-6) 관리자 구분
각 그룹별 1개이상의 정보가 등록되어 있으면 활성화된다.
[마스터]를 선택한다.
(그림4-7) 마스터 관리자 구분
로그인한 관리자는 로그인이 표시되며 관리자 정보가 등록된 마스터는 활성화된다.
로그인 표시 관리자를 선택하면 수정모드로 전환되며 수정방법은 다음 “4-4 마스터 관리자 수정”를 참조하며 활성화된 다른 관리자는 선택할 수는 없다.
비활성화된 마스터를 선택한다.
“(그림4-3) 관리자 정보 등록” 화면에서 정보를 등록 후 저장한다.
(그림4-8) 마스터 1 저장
[확인]을 선택하면 기본화면으로 전환된다.
마스터 관리자 수정
마스터 관리자가 로그인 한다.
로그인 정보가 정상이면 메뉴 아이콘이 활성화되고 정보가 불일치하면 다음 화면이 표시되고 [확인]을 선택하면 로그인 확인 창이 다시 표시된다.
(그림4-9) ID Password 불일치
메뉴에서 [관리자정보] 아이콘을 선택한다.
“(그림4-3) 관리자 구분”창에서 [마스터]를 선택한다.
“(그림4-4) 마스터 관리자 구분” 창에는 로그인한 마스터 관리자가 표시된다.
[마스터 1]을 선택하면 등록된 관리자 정보가 표시된다.
(그림4-10) 관리자 정보 표시

대기화면에서 마스터 관리자 / 서브 관리자 지문 스캔 -> [불출] 선택 ->  ‘[사격], [훈련], [정비], [근무], [미지급], [기타]’ 선택 -> ‘지문을 스캔 하세요!’ -> 사용자 지문 스캔 -> ‘XXX 님 보관함 문이 열렸습니다.’ 메시지 표시 -> 관리자 지문 스캔 -> ‘소총이 불출 되었습니다. 문을 닫아주세요!’ 표시 -> 대기 화면
(그림 8-6-1) 권총 보관함 불출 절차
불출 및 보관 시 최초 승인한 마스터관리자 / 서브 관리자 지문으로 최종단계에서도 동일하게 스캔 하여야 한다.
소총 불출 시 다음 사용자는 바로 지문을 스캔 하여 소총을 불출 할 수 있고 ‘소총이 불출 되었습니다. 문을 닫아주세요!’ 메시지는 불출 전까지 3초간 표시된다.
소총 보관
‘8.6 1) 소총 불출’의 불출 / 보관 모드 진입이 동일하고 절차 또한 불출 항목을 선택하는 절차를 제외한 모든 절차가 동일하다.
대기화면에서 마스터관리자 / 서브 관리자 지문 스캔 -> [보관] 선택 -> ‘지문을 스캔 하세요!’ -> 사용자 지문 스캔 -> ‘XXX 님 보관함 문이 열렸습니다.’ 메시지 표시 -> 관리자 지문 스캔 -> ‘소총이 보관 되었습니다. 문을 닫아주세요!’ 표시 -> 대기 화면
(그림 8-6-2) 소총 보관함 보관 절차
소총 보관함 알림 기능
소총을 보관함 문을 닫지 않았을 때
문을 열고 10초 후부터는 보관함 전면의 빨간색 LED가 0.5초 점멸한다.
소총을 보관함에 보관하였을 때
보관함 전면의 녹색 LED가 점등한다.
소총 보관함 시간 정보 표시
소총 보관함이 부팅하고 OMS프로그램 부팅 될 때와 24:00에 시간을 한번 수신한다.
